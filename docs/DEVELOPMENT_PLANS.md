# Wardrobe Builder — Development Plans

This document includes:
1. One-Person Development Plan  
2. Two-Person Development Plan  

---

# 1. One-Person Development Plan

### Overview  
A solo development path designed for someone working ~2 hours/day only on weekends.

---

## Phase 1 — Foundation (2–3 weeks)
- Project setup  
- Documentation (vision, roadmap, progress)  
- Tauri + React setup  
- Navigation skeleton  

---

## Phase 2 — Wireframes & UI Skeleton (2–3 weeks)
- Full desktop wireframes  
- Build basic UI components  
- Page layouts  

---

## Phase 3 — Wardrobe Core (4–6 weeks)
- File upload system  
- Basic background removal placeholder  
- Wardrobe grid  
- Edit modal (tags, category, color)  
- Local storage  

---

## Phase 4 — Outfit Builder (4–6 weeks)
- Drag-and-drop canvas  
- Place items visually  
- Save outfit presets  

---

## Phase 5 — AI Suggestions (4–8 weeks)
- Basic LLM integration  
- Suggest outfits from wardrobe  
- Weather + event logic  
- Basic prompt templates  

---

## Phase 6 — Polishing (2–4 weeks)
- UI cleanup  
- Error states  
- Settings page  
- Release build  

---

# 2. Two-Person Development Plan

### Overview  
Splits responsibility between:

### **You — UI/Product Lead**
- UI  
- Wireframes  
- React components  
- Zustand state  
- UX logic  

### **Friend — Backend/AI Lead**
- FastAPI backend  
- Database  
- AI pipelines  
- Image processing  
- Weather/Occasion logic  

---

# Phase Breakdown (Two-Person Team)

## Phase 1 — Setup (1–2 weeks)
**You:** Structure, pages  
**Friend:** FastAPI setup  

---

## Phase 2 — Wireframes & UI (2–3 weeks)
**You:** Wireframes, components  
**Friend:** Upload API, background removal  

---

## Phase 3 — Wardrobe Core (3–4 weeks)
**You:** Wardrobe grid UI  
**Friend:** Tagging AI + storage  

---

## Phase 4 — Outfit Builder (3–4 weeks)
**You:** Canvas builder  
**Friend:** Save outfit API  

---

## Phase 5 — AI Suggestions (4–6 weeks)
**You:** Suggestions UI  
**Friend:** LLM logic + prompt engine  

---

## Phase 6 — Finalizing (1–2 weeks)
Both test, polish, fix bugs.
