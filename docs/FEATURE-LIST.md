# 📦 Wardrobe Builder – Feature List

A complete list of all features: MVP, Phase 2, and Phase 3.

---

# 🧩 MVP Features (Phase 1)

## Wardrobe
- Upload item photos
- Auto background removal
- Auto cropping + centering
- Clean standard background
- Category detection (basic)
- Manual tagging
- Wardrobe grid view
- Filters: category, color

## Manual Outfit Builder
- Select items
- Layer them into outfit
- Save outfit
- View saved outfits

## AI Outfit Generator
- Suggest outfits using wardrobe items
- Simple rule-based AI
- Weather-aware logic
- Occasion-aware logic
- Provide 1–3 suggestions

## Smart Suggestions (Basic)
- Weather API integration
- Occasion selection
- Simple item suitability scoring

## Local Storage
- All wardrobe data local
- Outfits local
- Config/settings local

---

# 🎨 Phase 2 Features

## Template-Based Mannequin Preview
- Male/female models
- Simple front-facing pose
- Overlay clothing items
- Scaling and repositioning

## Items Needed Checklist
- Essential wardrobe items
- Mark as “owned / not owned”
- Auto-detect missing types
- Suggest wardrobe gaps

## Outfit Usage Tracker
- Worn history
- Simple calendar/log

## Cloud Sync (Optional)
- Multi-device sync
- User accounts

## Improved AI
- Better categorization
- More refined weather logic
- Early preference learning
